
## Space Fuel Run 🚀
A simple 2D side-scrolling space survival game.
## 📋 Overview
Space Fuel Run is a fast-paced 2D side-scroller where players navigate a spacecraft through deep space. The goal is to survive as long as possible by collecting fuel cells while avoiding cosmic obstacles. [2] 
This project was developed as an exploration of AI-assisted coding, utilizing Amazon Q CLI to streamline the development process, generate boilerplate, and debug logic. [3] 
## ✨ Features

* Smooth Side-Scrolling Mechanics: Responsive controls for an engaging arcade feel.
* Resource Management: Keep your fuel levels up to stay in flight.
* Dynamic Obstacles: Increasingly difficult patterns to challenge player reflexes.
* AI-Enhanced Codebase: Developed using Amazon Q CLI for optimized performance and clean code structure. [4, 5]
